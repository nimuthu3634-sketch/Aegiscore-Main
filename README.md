# AegisCore SOC Dashboard

**AegisCore** is an AI-integrated Security Operations Center (SOC) dashboard designed for small-scale and educational cybersecurity environments.  
The platform combines **Wazuh**, **Suricata**, **FastAPI**, **React**, **PostgreSQL**, and **TensorFlow/Keras** to provide centralized monitoring, AI-assisted alert prioritization, automated response workflows, and incident investigation capabilities.

AegisCore was developed as a custom SOC platform focused on improving visibility, usability, and alert prioritization for common cyberattack scenarios within a virtual lab environment.

---

## Key Features

- Centralized SOC dashboard for security monitoring
- AI-powered alert prioritization using TensorFlow/Keras
- Wazuh integration for endpoint monitoring and log collection
- Suricata integration for network-based threat detection
- Automated response workflow with audit logging
- Incident investigation and analyst notes
- Asset inventory and agent status monitoring
- Alert export and reporting capabilities
- Role-based authentication and access control
- Real-time dashboard updates through automated synchronization

---

## Supported Detection Types

AegisCore currently supports four primary detection categories:

| Detection Type | Description |
| --- | --- |
| `brute_force` | SSH/login brute-force attack attempts |
| `port_scan` | Network reconnaissance and port scanning |
| `file_integrity_violation` | Unauthorized file modification detection |
| `unauthorized_user_creation` | Unauthorized Linux user account creation |

## Wazuh Integration

AegisCore integrates directly with:

| Service | Purpose | Port |
| --- | --- | --- |
| Wazuh Manager API | Agent status monitoring | `55000` |
| Wazuh Indexer API | Alert ingestion | `9200` |

The FastAPI backend retrieves:

- Security alerts from the Wazuh Indexer
- Agent online/offline status from the Wazuh Manager API

Because AegisCore runs inside Docker while Wazuh services run on the Ubuntu Server host, Docker host gateway mapping is used:

```yaml
extra_hosts:
  - "host.docker.internal:host-gateway"
```

This allows the containerized FastAPI backend to communicate with host-based Wazuh services using:

```env
WAZUH_BASE_URL=https://host.docker.internal:55000
WAZUH_INDEXER_URL=https://host.docker.internal:9200
```

## AI / ML Alert Prioritization

AegisCore uses a TensorFlow/Keras model to prioritize already-detected alerts.

The AI model does **not replace Wazuh or Suricata**.  
Instead, it performs risk scoring and prioritization on alerts generated by those systems.

### AI Model Details

| Property | Value |
| --- | --- |
| Model Type | Multi-layer Perceptron (MLP) |
| Framework | TensorFlow / Keras |
| Dataset Size | 10,000 rows |
| Output Classes | Low / Medium / High / Critical |
| Test Accuracy | 98.6% |

### Supported AI Risk Levels

- Low
- Medium
- High
- Critical

### Enable AI Scoring

Inside `.env`:

```env
SCORING_STRATEGY=model
```

## Automated Response

AegisCore includes policy-driven automated response workflows.

Current automated response capabilities include:

| Detection Type | Action |
| --- | --- |
| brute_force | block_ip |
| file_integrity_violation | create_manual_review |
| unauthorized_user_creation | notify_admin |
| port_scan | notify_admin |

## Safe Lab Mode

By default, AegisCore operates in **safe laboratory mode**:

```env
AUTOMATED_RESPONSE_BLOCK_IP_BACKEND=ledger
AUTOMATED_RESPONSE_ALLOW_DESTRUCTIVE=false
```

This means:

- Automated response actions are recorded in the response ledger
- Real destructive firewall actions are disabled
- The system demonstrates SOC response logic safely

## Quick Start

### 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Aegiscore-Main.git
cd Aegiscore-Main
```

---

### 2. Create `.env`

Create a `.env` file in the project root:

```env
POSTGRES_DB=aegiscore
POSTGRES_USER=aegiscore
POSTGRES_PASSWORD=aegiscore_dev_password

DEV_SEED_ADMIN_USERNAME=admin
DEV_SEED_ADMIN_PASSWORD=AegisCore123!

DEV_SEED_ANALYST_USERNAME=analyst
DEV_SEED_ANALYST_PASSWORD=AegisCore123!

SCORING_STRATEGY=model

AI_DIRECT_BRUTE_FORCE_BLOCK_ENABLED=true

AUTOMATED_RESPONSE_BUILTIN_ADAPTERS_ENABLED=true
AUTOMATED_RESPONSE_LAB_ADAPTERS_ENABLED=true
AUTOMATED_RESPONSE_ML_BRUTE_FORCE_ENABLED=true
AUTOMATED_RESPONSE_BLOCK_IP_BACKEND=ledger
AUTOMATED_RESPONSE_ALLOW_DESTRUCTIVE=false

NOTIFICATIONS_ENABLED=true
NOTIFICATIONS_MODE=log
NOTIFICATIONS_RISK_THRESHOLD=85

WAZUH_BASE_URL=https://host.docker.internal:55000
WAZUH_USERNAME=wazuh
WAZUH_PASSWORD=YOUR_WAZUH_API_PASSWORD
WAZUH_VERIFY_TLS=false

WAZUH_INDEXER_URL=https://host.docker.internal:9200
WAZUH_INDEXER_USERNAME=admin
WAZUH_INDEXER_PASSWORD=YOUR_INDEXER_ADMIN_PASSWORD
WAZUH_INDEXER_ALERT_INDEX=wazuh-alerts-*
WAZUH_INDEXER_VERIFY_TLS=false
```

> `.env` should NOT be pushed to GitHub.

---

### 3. Start Containers

```bash
docker compose up --build -d
```

---

### 4. Run Database Migrations

```bash
docker compose exec api alembic upgrade head
```

---

### 5. Seed Default Data

```bash
docker compose exec api python -m app.db.seed
```
